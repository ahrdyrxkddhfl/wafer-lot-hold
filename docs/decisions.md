# 결정 기록

기술 선택과 버린 대안을 한두 줄씩 적는다.

## 0단계

- **모델 코드는 복사하지 않고 import한다.** 복사본이 원본과 어긋나면 가중치는 불러와지는데 판정만 틀어질 수 있다.
  노트북에만 있는 코드(pickle 호환 처리, 축소, 분할)는 import할 수 없어 출처 셀을 주석으로 적어 옮겼다.
- **분할은 원본 절차로 다시 만들고 기존 `split.npz`와 한 원소씩 비교한다.** 기존 파일에는 lotName이 없어서
  Lot 정보를 붙이려면 다시 만들어야 하고, 같은 분할임을 증명해야 12번 모델의 점수를 그대로 쓸 수 있다.
- **0단계에는 pytest를 두지 않는다.** 웨이퍼 저장소 가상환경에 pytest가 없고, 그 저장소는 수정하지 않는다.
  대신 검증 단계(해시, 분할 비교, 점수 재현)가 실패하면 exit 1로 멈추고 산출물을 쓰지 않는다.
- **산출물은 CPU 판정으로 만든다.** 다른 컴퓨터에서도 같은 결과가 나오게 하기 위해서다. 원래 점수는 MPS에서
  나왔으므로 MPS로도 판정해 비교한다(두 장치 예측 차이 0장).
- **웨이퍼 ID는 `{lotName}_W{waferIndex:02d}`.** Test 안에서 중복이 없음을 확인했다. 원본 추적용으로
  `src_row`(LSWMD.pkl 원본 행 위치)도 함께 남긴다.
- **정답 라벨은 판정 파일과 다른 파일·폴더(`evaluation/`)에 둔다.** 정답이 섞이면 AI 판정이 아니라 정답으로
  Lot을 멈추는 실수가 생길 수 있다.
- **정답 파일에 `label_source`(labeled/unlabeled)를 남긴다.** 원본 전처리가 라벨 없는 웨이퍼를 `none`으로 넣었기
  때문에, 평가 때 라벨 없음을 정상으로 치지 않고 따로 세기 위해서다.
- **웨이퍼 저장소 경로는 상대경로 기본값 + 환경변수 `WAFER_REPO`.** 절대경로는 계정 이름이 공개되고 다른 컴퓨터에서 맞지 않는다.
- **설정은 YAML(`pyyaml`).** 값마다 주석을 달 수 있고 웨이퍼 저장소 환경에 이미 있다. JSON은 주석을 달 수 없어 버렸다.
